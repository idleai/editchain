## Summary

r2 adds Codex as a first-class import source and carries its session, fork, and
subagent topology through EditChain's collapse, service, and VS Code rendering
layers. The importer does not hand-parse Codex conversation semantics: a small
projection bridge reuses the local Codex checkout's own rollout and protocol
types, then emits a versioned provider-neutral stream for EditChain.

The VS Code history path was redesigned around server-owned, per-row graph
geometry. Collapsed views retain structural endpoints even when intermediate
operations are hidden, so Codex subagents render as recognizable branches and
rejoins. Split/rejoin paths are rounded, change colour exactly at the lane
midpoint, and never terminate at an unconnected edge.

## Codex import architecture

### Native projection bridge

`tools/codex-session-exporter` is an isolated mini-workspace that links the
local sibling Codex checkout and reuses Codex's rollout reconstruction and
protocol types, including `ThreadHistoryBuilder` and `ResponseItem`. It emits a
versioned `editchain-v1` NDJSON projection. EditChain therefore owns the import
contract and normalization but does not maintain a second parser for Codex
thread, turn, and item semantics.

The helper is launched directly without a shell. The CLI supports:

- `--provider claude|codex`;
- `--codex-helper <path>`;
- repeatable `--codex-helper-arg <arg>`;
- the default Codex session hierarchy under `~/.codex/sessions`;
- workspace filtering from projected `sessionMeta.cwd`.

This boundary is also the migration path to a future Codex-provided
`rollout-export --format editchain-v1` command without changing EditChain's
neutral import contract.

### Incremental and durable import

- Codex discovery recursively and deterministically finds rollout files.
- Imports preserve raw bytes and large blobs, use durable cursors, tolerate
  incomplete trailing lines, and remain idempotent across restarts.
- Codex rewrite generations distinguish rewritten rollouts from append-only
  growth and keep subsequent imports deterministic.
- Item/turn folding handles repeated upserts, removed turns, tool lifecycle
  updates, session metadata, inter-agent records, and compaction records.
- Structured relationship notes are emitted as provider-neutral `ForkOf`,
  `SubagentOf`, and `ReconnectsTo` edges. Reconnects require explicit completion
  evidence; fork anchors are bounded by the source clock and are suppressed
  when explicit subagent provenance already explains the relationship.

## Effect on the existing Claude Code importer

Claude Code import was preserved, but its shared infrastructure was improved:

- blob and cursor sinks became explicit traits with memory and filesystem
  implementations;
- non-dry imports for both providers now persist blobs and cursors beneath the
  chain directory;
- Codex reuses the existing byte-level reader, cursor checks, source-time
  parsing, and neutral operation envelope;
- rewrite-generation counters remain Codex-specific, while Claude retains its
  existing fixed boot-generation behavior;
- Claude discovery, normalization, auto-import selection, and provider-specific
  semantics were not replaced by the Codex bridge.

The shared-surface change is therefore durable storage, not a conversion of
Claude sessions into Codex semantics. The full workspace and importer test
suites remained green.

## VS Code service and extension architecture

- The renderer moved from a single full-height SVG overlay to one small SVG per
  history row.
- The Rust service owns graph layout and returns each row's `above`, `below`,
  and `transitions` geometry with the window response. The webview remains a
  bounded, virtualized viewport rather than rebuilding the full graph.
- A cached `ViewSnapshot` keeps rows, filters, and layout on one consistent
  server-owned snapshot.
- Protocol identifiers that can exceed JavaScript's safe integer range are
  serialized as exact strings.
- `Open` responses expose accepted/duplicate/quarantined counts plus missing,
  corrupt, and unresolvable blob diagnostics.
- Extension-host epochs discard stale responses; panel restoration replays the
  open request; service restarts re-handshake instead of poisoning a newer
  generation; startup `Open` is unbounded while ordinary requests remain
  bounded.

## Collapse and subagent topology

The collapse pipeline now has an explicit representative invariant: every
hidden operation resolves to a canonical visible operation, while structural
notes remain edge bookkeeping rather than synthetic rows.

- Fork prologues are folded only within the exact source chain `(node, boot)`,
  preventing unrelated sessions from inflating branch lanes.
- Parent endpoints are canonicalized through the representative map.
- Structural anchors and targets survive message-only and kind filters, so
  hiding operational detail does not disconnect forks or subagents.
- Ordering uses a deterministic, edge-respecting topological pass, so causality
  stays downward even when source timestamps are inverted.
- Relation kinds are shipped to the extension and rendered as fork, subagent,
  and return badges.
- Window-clamped edges retain their visible jog rather than degenerating into
  disconnected coloured lanes.

The synthetic parent-plus-three-subagent projection test demonstrates that
`SubagentOf` and `ReconnectsTo` relationships survive import and collapse.

## Rounded, connected split/rejoin paths

- Adjacent cross-lane edges originate at the child node's midpoint. Rust no
  longer emits a duplicate source point or a source-lane top/bottom stub for
  that edge.
- A rendered transition must have a connected source and destination: each end
  is anchored either to the current row's dot or to a boundary continued by
  neighboring row geometry. Invalid dangling paths are omitted.
- Every transition is two SVG paths sharing the exact geometric midpoint seam:
  the source half uses the source-lane colour and the destination half uses the
  destination-lane colour.
- Butt caps make the categorical colour handoff gap-free. Quadratic elbows are
  clamped by lane spacing and row height; extreme compression uses a straight
  orthogonal fallback.
- Dots render last, SVG graph marks are hidden from the accessibility tree, and
  legacy hard horizontal connector lines are gone.

## Explicit non-goals

r2 does not package the local Codex bridge for general distribution, change the
EditChain on-disk codec version, replace the Claude Code parser, archive the r2
sessions themselves, publish either local repository, or add direct Codex
session support to an upstream release. Those are follow-on concerns.
